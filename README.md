# FlatHMCL
一个第三方的HMCL Flatpak打包

> [!NOTE]
> 当你使用这个版本的HMCL出现了问题时，请不要把问题提交到HMCL官方的issues，而是提交到[本项目的issues](https://github.com/TheOninesixY/FlatHMCL/issues)

## 安装

- [下载在线安装包（推荐）](https://flrepo.onsy.qzz.io/FlatHMCL.flatpakref)
- [下载离线安装包](https://flrepo.onsy.qzz.io/FlatHMCL.flatpak)
> [!WARNING]
> 离线安装包在安装后将无法获取更新
