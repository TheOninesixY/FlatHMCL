FlatHMCL

为 Linux 桌面及 SteamOS 打造的独立 Flatpak 打包版本 Hello Minecraft! Launcher。基于 OpenJDK 21 与 Freedesktop 24.08 平台构建，支持沙盒隔离与启动时自动同步上游最新构建。

code GitHub 仓库

info 分发与安装说明

本项目为独立打包与维护，不会上架 Flathub。无需手动下载安装包，直接在终端中运行下方的远程安装命令即可一键完成安装。

终端直接安装远程文件 terminal
flatpak install https://onsy.qzz.io/FlatHMCL/io.github.theoninesixy.FlatHMCL.flatpakref

主界面概览

运行于 Flatpak 沙盒环境下的 FlatHMCL 启动器界面

打包特性

sync

启动自动同步上游

内置运行机制，启动时自动通过 GitHub API 检测并拉取 HMCL 上游最新稳定 Release JAR 文件；离线或网络故障时自动回退启动本地已有版本。

terminal

集成 OpenJDK 21

基于 Freedesktop Platform 24.08 并内置 OpenJDK 21 运行环境，适配现代 Minecraft 版本，免去手动配置 Java 环境变量的繁琐流程。

security

规范权限与持久化

独立沙盒保护，规范映射 ~/.minecraft 与 ~/.hmcl 目录，既能保护宿主机文件安全，又能与现有游戏配置无缝衔接。

desktop_windows

Wayland 与图形加速

开放 Wayland、X11、DRI 硬件加速与 Pulseaudio 音频支持，保障在各 Linux 桌面及 SteamOS (Steam Deck) 下的原生流畅度。

本地编译与构建

1. 获取仓库代码

git clone https://github.com/TheOninesixY/FlatHMCL.git && cd FlatHMCL

2. 编译并直接安装至当前环境

flatpak-builder --user --install --install-deps-from=flathub --force-clean build-dir io.github.theoninesixy.FlatHMCL.yml

3. 打包生成 FlatHMCL.flatpak

flatpak-builder --repo=FlatHMCL --force-clean build-dir io.github.theoninesixy.FlatHMCL.yml
flatpak build-bundle FlatHMCL FlatHMCL.flatpak io.github.theoninesixy.FlatHMCL

4. 运行应用

flatpak run io.github.theoninesixy.FlatHMCL
